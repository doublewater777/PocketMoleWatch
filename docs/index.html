Support

Pocket Mole Watch is a quick Apple Watch arcade game built for short, playful 30-second sessions. If you need help, have feedback, or want to report a bug, use the contact details on this page.

Get Help

When contacting support, include your Apple Watch model, watchOS version, and a short description of the problem. Screenshots or clear steps to reproduce the issue are also helpful.

Common topics
