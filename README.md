# Pocket Mole Watch

Pocket Mole Watch is a fast Apple Watch arcade game built with SwiftUI. Tap popping moles, build streaks, and chase a high score in quick 30-second rounds.

## Project Structure

- `PocketMoleWatch/` - watchOS app source, assets, audio, and localizations
- `PocketMoleWatch.xcodeproj/` - Xcode project
- `PocketMoleWatchContainerAssets.xcassets/` - iOS container app assets
- `docs/` - public support and privacy pages for App Store metadata
- `project.yml` - XcodeGen project definition

## Build

Open `PocketMoleWatch.xcodeproj` in Xcode and run the `PocketMoleWatch` scheme.
